# anizmo.github.io

Personal website of Anuj Ashok Potdar, served by GitHub Pages at <https://anizmo.github.io/>.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The homepage. All current content lives here. |
| `css/site.css` | The only stylesheet. Used by every page. No framework. |
| `images/anuj.jpg` | Source profile photo. |
| `images/anuj-320.jpg`, `images/anuj-640.jpg` | Square crops of the photo used on the page (1x and 2x). |
| `images/favicon.png` | Browser tab icon. |
| `sitemap.xml`, `robots.txt` | Search engine metadata. |
| `desirider.html`, `comealivecards.html`, `logs.html`, `seawatersports.html`, `cuddle.html`, `ingram.html` | Earlier project pages (2016 to 2021), linked from the bottom of the homepage. Same layout and stylesheet as the homepage. |
| `images/*.jpg` (other) | Header images for the earlier project pages. |
